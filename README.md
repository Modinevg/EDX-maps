# EDX-maps

Программа для обработки EDX (EDS) спектральных изображений SEM и (S)TEM. Она фитует спектр, определяет
элементы, строит карты элементов, делает PCA, накладывает карты на электронное изображение и экспортирует
результаты в PowerPoint.

*EDX spectrum-image processing GUI for FEI TIA and EDAX Genesis / TEAM data: spectrum fitting, element
identification, elemental maps, PCA, overlay on the electron image. The interface is in Russian; the
PowerPoint export is in English.*

## Поддерживаемые форматы

**Чтение**

| Система | Файлы | Что берётся из файлов |
|---|---|---|
| FEI / Thermo Fisher **TIA** (TEM / STEM) | `.emi` + `_N.ser` (открыть `.emi` или любой `_N.ser` серии) | спектральное изображение, калибровка энергии и пикселя, параметры съёмки, обзорное изображение, HAADF |
| **EDAX Genesis / TEAM** (SEM) | `.spd` — карта, `.lsd` — линейный скан, `.spc` — спектр (форматы `.spc` 0.61–0.70) | из `.spc` с тем же именем — калибровка энергии, ускоряющее напряжение, разрешение детектора, живое время, элементы, найденные EDAX; электронное изображение `.bmp` с калибровкой `.ipr` |
| Электронные изображения SEM / STEM (для наложения карт) | TIFF, BMP, PNG, JPEG | калибровка из метаданных FEI / Thermo Fisher и Zeiss TIFF или из `.ipr` EDAX; информационная панель SEM обрезается |

**Экспорт**

- Карты элементов и композит: PNG, TIFF (float32), NPZ, CSV.
- PCA: собственные значения и нагрузки (CSV), карты счетов (TIFF), всё вместе в `pca.npz`.
- Презентация PowerPoint (`.pptx`, на английском):
  - обзорное изображение с рамкой области карты;
  - композит с легендой и параметрами обработки;
  - карты всех элементов.

## Возможности

- **Фон**: SNIP; по минимумам (алгоритм DM-скрипта «Autobackground SI from minima»); полином по окнам.
- **Фит спектра**:
  - деконволюция серий K / L / M, escape-пики и пики наложения (pile-up);
  - уточнение калибровки энергии, разрешения, хвоста и порога детектора;
  - NLLS-подгонка формы пиков.
- **Автоопределение элементов**: итеративный фит остатка с проверкой всех серий элемента и условия
  перенапряжения. Можно также взять список элементов из файла EDAX.
- **Карты**:
  - попиксельный MLLS-фит, «окно − фон» или окно; фон по фазам;
  - проверка, не зависит ли карта от модели фона;
  - удаление горячих пикселей (по DM-скрипту «Point Blemish»);
  - биннинг, сглаживание, общая шкала карт.
- **Композит**: цветной композит и наложение карт на электронное изображение.
- **PCA**:
  - предобработка: мёртвые каналы, дрейф энергии, плохие пиксели;
  - взвешенный (пуассоновский) PCA, граница шума Марченко–Пастур;
  - ручной выбор компонент, биннинг, локальный PCA по плиткам;
  - проверка карт PCA против исходных.
- **Деконволюция Ричардсона–Люси** спектра.

Подробное описание — кнопка **«Справка»** в программе.

## Установка и запуск (Windows)

1. Скачайте проект: **Code → Download ZIP** или `git clone https://github.com/Modinevg/EDX-maps.git`.
2. Один раз запустите **`setup_edx_env.bat`**.
   - Он скачает Python 3.12 и библиотеки, около 170 МБ, в `%LOCALAPPDATA%\EDX_processing`.
   - Права администратора не нужны, установленные в системе Python не затрагиваются.
   - Чтобы удалить, удалите эту папку.
3. Запускайте **`run_edx_gui.bat`**. Можно перетащить на него файл данных, тогда он сразу откроется.

С уже установленным Python 3.12:

```
pip install -r requirements.txt
python edx_gui.py [файл.emi | карта.spd]
```

На других ОС программа не проверялась. Используемые библиотеки (PyQt5, pyqtgraph, numpy, scipy, matplotlib)
кроссплатформенные.

## Файлы

| Файл | Назначение |
|---|---|
| `edx_gui.py` | интерфейс (PyQt5 + pyqtgraph) |
| `edx_core.py` | вычисления без интерфейса: чтение файлов, фон, фит, автоопределение, карты, PCA |
| `edx_xray_lines.py` | таблица рентгеновских линий; создаётся `build_xray_lines.py` из базы xraydb |
| `setup_edx_env.bat`, `requirements.txt` | установка Python и библиотек (версии зафиксированы) |
| `run_edx_gui.bat` | запуск программы |
| `CHANGELOG.md` | журнал изменений |

`edx_core` можно использовать из своих скриптов:

```python
import edx_core as core

si = core.load_si('Live Map 1.spd')      # или 'image.emi'
print(si.data.shape, si.voltage)         # (ny, nx, каналы), кВ
spectrum = si.sum_spectrum()             # суммарный спектр, по шкале si.energy (кэВ)
```

## Данные о линиях

Энергии рентгеновских линий и выходы флуоресценции взяты из [xraydb](https://github.com/xraypy/XrayDB)
(M. Newville, лицензия MIT): W. T. Elam, B. D. Ravel, J. R. Sieber, *Radiat. Phys. Chem.* **63** (2002) 121.
